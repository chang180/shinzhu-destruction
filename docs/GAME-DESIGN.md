# 13 使徒戰役與遊戲設計

更新：2026-09-08。以下數值是可實作的平衡起點；P03／P08 必須以測試調整並在 `BALANCE.md` 鎖版，不宣稱已平衡。

## 1. 作品定位

玩家是反派學院的新生，認真準備一場浮誇的「城市毀滅畢業考」。幽默來自角色氣勢、招式排場與城市防線的反應；戰鬥本身要讓觀察與布局有回報。名稱沿用使用者設定，角色、世界觀、校徽、使徒、構圖、台詞與音樂獨立創作。

13 使徒是學院封存的 13 種原創禁術意志，每關授予玩家一種使徒修正；不是移植任何既有作品的名單，也不是讓玩家扮英雄消滅 13 個敵方怪物。真正對手是有預告、有資源限制、會調整的虛構城市防禦系統。

玩家勝利＝在該關回合內使城市核心韌性歸零；城市守住＝回合耗盡仍有韌性。第 13 關勝利才觸發全戰役終幕。13 關與每關 10～18 回合是不同概念。

## 2. 玩家流程與資訊

1. 學院首頁／續玩 → 13 個使徒封印的選關頁。
2. 戰前情報：本關獨特規則、回合上限、城市防線、使徒能力、來源觀測期間及情境品質；顯示本關新機制的一個例子。
3. 每回合看城市下一步預告，選擇試探、破防、干擾、蓄勢或終招；施招後看圖片與音效演出、數值差異及城市回應。
4. 結算 → 關鍵回合複盤 → 重試相同情境／繼續下一關。重試預設沿用 seed 與快照以便學習；主動開「最新情境」才換資料。

預告必須說明將發生什麼、何時發生及可對應的手段；前三關逐步教學，後期可隱藏部分增益細節但不能藏起致命規則。提示指出當前局面與代價，不直接給全遊戲通用九招答案。

## 3. 戰鬥資源與技能起點

### 3.1 局面

- 城市核心韌性 `0～100`；三系防線 `0～100`，基準各 40，各關可改；另有有期限的護盾與修復資源。
- 玩家「惡意」初始 6、上限 10，每回合開始回復 2，首回合不額外回復；三系印記各 `0～3`，滿格時不繼續溢出。
- 城市回應按關卡腳本及有限資源執行；最多一個主要回應／回合。連續使用同系進攻會增加可見的該系抗性，換系或干擾可消退。
- 全部效果有作用目標、開始／到期回合及最大層數。局面與事件包含冷卻、連攜、抗性、破綻、使徒階段與下一次城市意圖。

### 3.2 共用技能組

| 技能型 | 初始成本／冷卻 | 作用 | 策略代價 |
|---|---|---|---|
| 試探術（水／熱／土地各一） | 惡意 2，無冷卻 | 基礎衝擊 6、對應防線 -8、同系印記 +1 | 穩定但不能靠單系連按忽略抗性 |
| 破陣術（三系各一） | 惡意 4，冷卻 2 回合 | 基礎衝擊 12、對應防線 -20、同系印記 +1 | 高成本，需抓防線缺口；冷卻時要換策略 |
| 擾序術（三系各一） | 惡意 3，冷卻 3 回合 | 基礎衝擊 4、防線 -4，取消一次**可打斷且同系**的預告回應 | 阻止修復或換盾，但犧牲即時輸出；不可取消無關系別 |
| 蓄勢 | 成本 0，無傷害 | 回復惡意 3，並使目前最高一項適應抗性下降 1 層 | 消耗一回合，城市仍然行動 |
| 使徒終招 | 惡意 6、三系至少各 2 印記，冷卻 4 回合 | 消耗全部印記；基礎衝擊 32、三系防線各 -8；附本關使徒修正 | 不保證秒殺，護盾或時機錯誤仍可大幅折損 |

UI 用各系原創招式名包裝技能型，代碼保持穩定。未滿終招條件時按鈕不可施放並指出缺項，不以誤觸白扣全部資源製造難度。水／熱／土地系與 SDGs 的連結保留在資料說明，不強迫每回合閱讀教育段落。

### 3.3 結算順序與公式

每回合：確認版本及技能合法 → 扣惡意／記錄輸入 → 套使徒／情境修正 → 計算城市核心衝擊 → 扣對應防線 → 更新印記、連攜與打斷 → 若核心歸零立即玩家勝利 → 執行未被取消的城市回應 → 更新效果期限與冷卻 → 檢查回合耗盡 → 產生下回合預告及資源回復。

初始核心衝擊公式：

```text
effective_defense = clamp(對應防線 + 適應抗性加值, 0, 100)
raw = floor(base × (1 + environment_modifier) × combo_multiplier
            × (1 - min(0.75, effective_defense / 120)))
absorbed = min(可用護盾, raw)
core_damage = clamp(raw - absorbed, 0, 目前核心韌性)
```

防線以**命中前**值計算；終招使用三系有效防線的平均值。一般連續三次不同系進攻的最後一招 `combo_multiplier=1.2`，其他為 1；蓄勢或終招中斷連攜。適應抗性：同系連續第 2 次及之後每次 +1 層、最多 3，每層加防線 10；換系後原系 -1 層。P03 要明確編碼「本次命中後加層」，不能讓隱藏預判影響本次傷害。

通用破綻：任一防線首次降到 0 時，下一個玩家行動獲得 `combo_multiplier` 額外 ×1.25，消耗後不能靠同一個已為 0 的防線重複觸發；防線恢復到至少 20 後才可重新觸發。所有加乘及上限寫入事件。各關若覆盖公式，必須有具名規則和提示。

冷卻 `2` 指接下來兩個玩家決策回合不可使用；以 `ready_on_turn` 定義，避免施放當回合先減造成少一回合。核心在玩家行動中已歸零就立即贏，不先修復救回城市；其他邊界以相同規則固定。

進度只保存是否通關與最佳表現，不以永久增加傷害代替策略。重玩可挑已完成關卡；第 13 關的獎勵是全章勝利，不能把先前每關勝利都直接當全城市最終歸零。

## 5. 資料必須改變決策，而非只出現在頁尾

戰前顯示真實觀測摘要、對應遊戲修正及模型限制；例如水庫情境可能使水系防線偏高，玩家因此改先破土地防線，並在水系補給前準備干擾。不同資料情境至少能改變一个最佳窗口、技能順序或資源安排。

驗收以相同 seed 的低／中／高資料情境，證明至少一組決策或最佳路線有差異；同時各情境都保留可解路徑。沒有適合欄位時顯示中性修正，不把公園用地面積直接變成「實際降低 2°C」。同一局重播必須帶原始快照與映射版本。

## 6. 難度與可解性驗證

- 每關固定低／中／高三組情境 × 至少 100 個固定 seed。首版能完全無隨機；有隨機則只在明列小範圍內選擇城市事件，不能隨機宣告必敗。
- 比較合法隨機、單系連按、舊三系循環後終招、讀預告的貪心策略、會布局的規劃策略；記錄勝率、回合、傷害浪費及關鍵防守觸發率。
- 初始驗收目标：4～13 關規劃策略勝率比合法隨機高至少 25 個百分點，且至少達 70%；單一固定循環不能在所有中後期關卡／情境達 80% 勝率。若自動策略本身寫錯，先修策略，不能因此削弱城市機制。
- 每關每組資料情境至少兩條不同有效路線；對具隨機分歧的 seed，要有可重現通關證據或求解驗證，沒有解的 seed 不可正式發布。
- 真人初稿目標：1～3 關首次嘗試或一次重試後多數可通過；4～9 關需要調整策略；10～13 關不能無腦首通，也不應十次仍看不懂。至少 5 位新玩家試玩代表關並記錄卡點；小樣本只作調整依據，不冒充統計結論。
- UI 難度標籤以實際驗證命名。調整優先順序：資訊清楚 → 可對應的防守 → 成本／窗口 → 數值；不單純加血或砍傷害。

## 7. 施招後的事件與演出

一次施招要呈現「玩家企圖 → 使徒／技能切入 → 城市反應 → 戰果 → 下一步」，詳見[美術音效規格](ART-AUDIO-SPEC.md)。普通命中、護盾吸收、打斷、破防、連攜、終招、城市修復都要有不同 cue。戰鬥日誌保留作檢索，但不是主要回饋。

伺服器先固定結果，Vue 再播放事件序列；動畫進行中鎖定重復提交，仍可跳過、靜音或開啟低動態。暫停／背景分頁／斷線恢復後不能多結算回合。每次回饋必須顯示實际命中、吸收與修復，而不是只寫一個誇大技能名。

## 8. 複盤：用玩家行動形成因果鏈

複盤輸入為完整行動／事件、凍結快照、規則版本與 seed，先依結果產生事實，再選符合條件的文案。首版採可測試的規則與模板，不依賴即時 LLM。

1. 找出每局 2～4 個關鍵回合：有效／浪費的終招、成功／失敗的打斷、首次破綻、造成最大傷害差的決策、修復與階段轉換。短局證據不足可只列 1 個，不硬補假事件。
2. 每項以「第幾回合、哪個動作、造成什麼差值、如何影響後續」呈現，點選可回看當時畫面與狀態。
3. 反事實比較只替換一個當時合法行動，固定快照與 seed，依明列規則繼續模擬。後續原行動若不合法，使用同一固定替代策略，並註明此限制；隨機採按回合／事件類型的獨立序列，避免多抽一次亂數使比較失真。
4. 只有真的重算才能說「若第 6 回合改用干擾，最終會剩 8 韌性」。未重算只能說當回合直接差值，不能推測整局必勝。
5. 每種結局有自己的標題、鏡頭、音樂、指標與敘事，禁止只替換一個 won 布林值共用整段正文。

### 8.1 城市防守成功＝玩家挑戰失敗

順序：城市度過衝擊的 3～5 秒演出 → 防守關鍵事實 → 玩家最有威脅的一次行動 → 導致失敗的 1～2 個決策 → 可在下局驗證的具體調整。

示意文案（實作必須以真實紀錄填入）：

> 你在第 4 回合撕開了土地防線，卻把第 5 回合留給了蓄勢。城市趁這個空檔完成回補。不是你的招式不夠大，是你把破口的使用期限讓給了對手。

可以犀利、幽默，不只是「城市靠綠地守住了」。先承認玩家有做對什麼，再指出真正的失敗機制。

### 8.2 城市毀滅成功＝玩家真正勝利

順序：8～12 秒可跳過的終焉連續分鏡 → 使徒及學院盛大認可 → 連攜／破防／終招的實際高光 →「城市失守檢討」→ 下一關或第 13 關全章終幕。

要直接肯定玩家策略與勝利；不能马上取消成就、轉成保護城市小教室。失守檢討针對虛構制度缺口：備援共用依賴、透支未來修復、重複忽略明確預兆、資源分配僵化。數據只支持情境，不指控真實城市或機關確有這些缺陷。

示意文案（僅適用事件有證據時）：

> 你在第 8 回合截斷共同補給，第 10 回合讓終招穿過了三道空殼防線。畢業通過。這座模擬城市把三份備援報表誤認成三條退路，直到它們一起停擺，才發現自己從來只有一條路。

第 13 關追加 3～5 幅全章分鏡、13 枚原創封印解放與主要戰績；戰役總結只引用仍有保存依據的關卡摘要，不能替遺失的紀錄杜撰細節。

### 8.3 複盤驗收案例

同一關分別保存：成功打斷、錯過打斷、終招被盾吸收、抓住破綻終招四種路線；複盤必須有不同因果段落。每關至少一勝一敗共 26 份樣本；同一事實不得在勝利說「城市守住」、在失敗又說「城市失守」。兩套畫面的語意與色彩不能只靠換背景區分。
