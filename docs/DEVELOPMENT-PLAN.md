將《我的反派學院：超認真毀滅新竹計畫》重製為 Laravel + Vue 的 13 關策略遊戲。本文件供不同 AI 或開發者依階段接手，必須交付可執行成果及驗收證據，不能以「完成規劃」代替功能完成。

## 3. 現況與遷移理由

- `docs/game.js` 是單場 12 回合遊戲，並沒有 12 個既有關卡。新版 **13 關** 與各關的 **回合數** 必須分開。
- 舊版三系各放三次再施放終招即可獲勝，固定套路不要求玩家閱讀局勢；介面標示「地獄難度」也缺少實測依據。
- `docs/app.js` 的戰報主要依最常用系別選固定文字，無法解釋關鍵決策；勝利結局仍顯示「這次守住城市的，是什麼？」。
- `server.js`、根目錄 npm 設定是 API 連線實驗，不是 Laravel 服務；`public/index.php` 目前只是占位頁。
- README 記載 GitHub Pages 發布 `main:/docs`。新增開發文件將位於既有發布樹；文件不得包含金鑰、個資、私密主機設定或未公開報名附件。
- [Hostinger 實測](../api-probe/HOSTINGER-RESULT.md)及[資料可行性盤點](../api-probe/DATA-SOURCES-FEASIBILITY.md)是資料選型依據。舊探測器白名單仍只有縣府主機，不能把舊探測器全部失敗誤判為部會資料不可用。

## 4. 已採用的規劃預設

以下是可直接執行的設計預設，不是等待使用者逐項批准的阻擋條件。若使用者另有要求，再留下決策紀錄調整。

1. 單人、免註冊、繁體中文，桌機及手機都可玩；匿名存檔保留關卡進度。首版不加入多人、排行榜、付費或管理後台。
2. Vue 3 + TypeScript + Vite；Laravel 提供同源頁面殼與 JSON 介面。首版不需要 SSR、Inertia、常駐 Node、Redis、WebSocket 或常駐 queue worker。
3. 玩家是反派學員；13 使徒是玩家解鎖的原創禁術人格／災變意象。每關敵對方仍是虛構城市防線，不能改成玩家保護城市、打敗使徒。
4. 13 關使用虛構的新竹城市切片。保留真實地名與資料來源的辨識度，但暫不把 13 使徒硬配 13 鄉鎮市的「真實弱點」。資料仍完整涵蓋可取得的 13 鄉鎮市。
5. API 資料是有限幅度的遊戲情境修正；一場開始後凍結快照。斷線有標示清楚的備援情境，不能因今日水情讓某關無解。
6. 圖片在開發階段生成後以靜態資產部署；允許下載免費開源／開放授權的原創致敬、特效、場景與音效素材搭配使用，保存來源與授權。本次先取得 4 圖／4 音效候選，詳見素材來源清單；遊戲進行中不呼叫生成圖片、音樂或文字的付費服務。
7. 單關初始目標 3～6 分鐘，後期 6～10 分鐘；可跳過過場、快轉、靜音及減少動態。總時長是待玩家實測的假設。
8. 核心循環完成前不增加大型劇情系統；完整 13 關、兩種結局及正式美術音效仍屬首版必要範圍。

## 5. 階段順序與依賴

`P00 → P01 → P02 → P03 → P04 → P05 → P06 → P07 → P08 → P09`

這是預設串行交付順序，方便分派給不同 AI。每次只指派一階段；前一階段未通過，不以完成後續畫面掩蓋缺口。只有明確拆好檔案責任與固定介面，才另行安排平行工作。

### P00｜版本、主機與遷移基線

**輸入：** README、兩份 API 報告、本組規格、現有遊戲與測試。

**工作：**

- 查當日 Laravel／Vue／Boost 最新穩定版與 PHP、Node 要求，留下版本與查閱日期；不得因舊教學而降版。
- 記錄本機與 Hostinger 的 PHP CLI／Web 版本、必要擴充、SQLite 檔案鎖、Composer、SSH、cron、網站根目錄能力及資源配額。
- 記錄舊版 commit、既有測試、Pages 入口、需保留的 API 報告。新 Laravel 骨架先在暫存目錄建立，再有選擇地合入根目錄，不覆蓋 `.git`、文件或本機未提交變更。
- 產出舊 Node 探測器隔離方案及 Laravel 正式目錄方案；不再以 Node Web App 作為正式部署前提。
- 查閱現有素材來源 manifest，需要時下載有明確授權的少量候選，標示用途、檢視狀態與尚未整合部分。

**交付：** `docs/phase-reports/P00.md`，包含版本／環境表、遷移檔案清單、實測或待驗項目。

**驗收：** 所有環境結論區分「已驗證／待主機驗證」。本機符合最新穩定版需求可進 P01；暫無主機存取可先做本機工作，正式主機適配保持待驗，必須在 P09 前補齊。若已證實主機不支援最新版本，提出具體方案差異，不能默默改成舊 Laravel 或 MySQL。

### P01｜Laravel + Vue + SQLite + Boost 基礎

**前置：** P00 本機門檻通過。

**工作：**

- Laravel 位於 repo 根目錄；建立 Vue 頁面殼、TypeScript、Vite、測試與程式格式工具，重整根 npm scripts。
- SQLite、file cache、file session、sync queue 作為基準設定；提供不含秘密的 `.env.example`。
- 將 Node 連線實驗的啟動設定隔離至 `api-probe`，保留紀錄及原本可重現的探測功能。
- 按技術規格完成 Boost 非互動全選、產物驗證與 MCP 實際呼叫；安裝後先讀生成的開發指示，再開始應用功能。
- 將本專案約束加入 `.ai/guidelines/`，保留 Boost 管理的指引；驗證更新指引不會遺失專案要求。

**交付：** 可啟動的 Laravel + Vue、SQLite migrations、lockfiles、可重跑的 Boost 設定腳本、`docs/phase-reports/P01.md`、`docs/BOOST-SETUP.md`。

**驗收：** 乾淨安裝可載入 Vue；測試資料庫為 SQLite；正式建置成功；Boost 完成條件全部有證據。此時只驗證頁面殼，不宣稱完整遊戲完成。

### P02｜資料轉接、快照與備援

**前置：** P01。

**工作：** 以 Laravel HTTP client 串接三個既定資料集，保存實際下載網址、樣本欄位、單位、行政區／水庫代碼與觀測期間；建立更新命令、清洗、快取、不可變快照、來源狀態及固定情境 fixture。

**交付：** 三個 adapter、標準化資料契約、`docs/DATA-CONTRACT.md`、fixtures、排程定義、`docs/phase-reports/P02.md`。

**驗收：** 三來源成功及逾時、403、429、HTML 假成功、缺欄位、過期、零值／缺值分別驗證；資料失敗不覆蓋好快照；假資料有明確標記。至少一個正式主機 PHP 解析樣本於 P09 前補齊；每回合不得下載上游資料。

### P03｜可重播的戰鬥引擎與平衡初稿

**前置：** P02 資料契約固定。

**工作：** 實作伺服器權威狀態、技能成本／冷卻、城市防禦預告、破綻、抗性、階段轉換、凍結快照、事件序列、重送去重、回合版本與存檔。先用三個代表情境驗證規則，不急著複製 13 份 UI。

**交付：** PHP 領域引擎、HTTP 契約、`docs/BALANCE.md`、可重現種子與策略腳本、`docs/phase-reports/P03.md`。

**驗收：** 相同輸入得到相同事件與結局；非法／重複行動不多扣資源；城市每回合行為可解釋；存在至少兩種可行策略；舊版九次集印記必殺套路不再保證成功。將遊戲設計中的初始數值正式鎖成 `rules_version`，不得保留「傷害之後再決定」的實作空白。

### P04｜一關完整體驗切片

**前置：** P03。

**工作：** 將第 1 關從選關、戰前情報、施招、過場、敵方回應、存檔、初步勝敗複盤到重玩完整接通。依美術規格**實際生成**首批主視覺、使徒、場景及技能切入圖，從下載候選選用適合的特效與音效；可繼續搜尋原創開放授權致敬作品，核對後下載與整合。

**交付：** 可玩第 1 關、首批素材及生成紀錄、桌機／手機截圖與一段完整操作錄影、`docs/phase-reports/P04.md`。

**驗收：** 普通招／破防／終招有明確視聽差別；按跳過不影響結果；網路重試不中斷局面；兩種勝敗均可觸發；不以純 CSS 圓圈或日誌代替要求的圖片。完成一次真人試玩並記錄困惑點，作為展開 13 關前的調整依據。

### P05｜13 關策略與進度系統

**前置：** P04 完整切片通過。

**工作：** 按 13 關表實作各關獨有防守規則、使徒修正、階段變化、預告與提示；順序解鎖、重玩已完成關卡、匿名續玩；完成 13 關設定驗證器。

**交付：** 13 份關卡定義、每關至少兩條通關策略與一條典型失敗策略、固定情境結果、`docs/phase-reports/P05.md`。

**驗收：** 不是改名字與血量的 13 份複製品；前、中、後期有策略差異；資料修正上下界均能通關；不能跳關竄改完成紀錄。每關提供一般通關與城市守住的可重現紀錄。後期具多階段防守，但不靠無預警必敗事件製造難度。

### P06｜完整原創美術、過場與音效

**前置：** P05 關卡及事件 ID 固定。

**工作：** 完成 13 使徒、13 場景、技能切入、結局分鏡及音效清單；依事件驅動演出；加入圖片壓縮、逐關載入、減少動態、靜音及快轉。

**交付：** 上線素材、資產 manifest、提示詞與版本紀錄、授權來源紀錄、相似性檢查紀錄、`docs/phase-reports/P06.md`。

**驗收：** 所有必要素材存在、實際被遊戲引用且無 404；手機無遮擋或橫向溢出；文字由 UI 排版；不含既有作品角色、標誌、招式名、辨識性服裝／配色組合或音樂旋律重製。不能保證法律零風險，但必須有可供人工檢視的原創與來源證據。

### P07｜行動複盤與兩種獨立結局

**前置：** P05 事件紀錄與 P06 結局素材可用。

**工作：** 用玩家回合與事件產生關鍵決策、因果鏈及可重播的反事實比較。防守成功說明城市如何應對玩家；玩家毀滅成功有盛大演出、成果肯定與尖銳城市失守檢討。第 13 關勝利追加全章終幕。

**交付：** 規則式複盤服務、兩套文案／畫面／音效、每關兩種結局範例、`docs/phase-reports/P07.md`。

**驗收：** 文案能指到實際回合與數值，不只看施招次數；更換關鍵行動後，戰報跟著變；反事實結果來自模擬；勝利頁不出現防守成功標題或硬轉教訓玩家保護城市。全 13 關至少 26 份結局樣本完成檢視。

### P08｜難度、可靠性、無障礙與效能驗收

**前置：** P07。

**工作：** 執行遊戲設計的固定情境／策略矩陣，邀請至少 5 位未參與開發者試玩前期與後期代表關；驗證音訊解鎖、鍵盤、低動態、斷線、重新整理、雙分頁、過期存檔與更新版本續玩。

**交付：** `docs/QA-REPORT.md`、平衡調整後的版本、效能／資產大小結果、問題清單、`docs/phase-reports/P08.md`。

**驗收：** 達到遊戲及技術規格的明列門檻；所有必驗項都有結果。測試目標未達就調整後重測受影響項目，不改報告數字湊通過，也不把機器策略勝率當真人體驗證據。

### P09｜Hostinger 正式部署與交接

**前置：** P08；P00／P02 的主機待驗項已補齊。

**工作：** 建立含前端產物與正式 PHP 依賴的發布包；網站只公開 Laravel `public`；配置 SQLite 持久路徑、排程、快照暖機、備份與回退；實際走一輪兩種結局。更新 README 正式網址與啟動說明。

**交付：** `docs/DEPLOYMENT.md`、`docs/OPERATIONS.md`、`docs/phase-reports/P09.md`、發布版本與回退版本。

**驗收：** 正式主機 PHP 取得三來源、重跑 cron 不重疊、部署不清空存檔；`.env`／SQLite／logs／vendor 不可公開；正式環境停用 Boost；備份還原及回退演練通過。GitHub Pages 明確標為歷史原型並連至新版，不把 Laravel 原始碼當靜態站發布。

## 6. 共通完成條件

每階段要有：實檔／程式、必要測試、實際驗證輸出、未決項、階段報告、更新進度表。測試未執行就寫「未執行＋原因」；不得寫成通過。除本次文件階段外，只有說明文字不算交付功能。

完成指派階段後停止擴張範圍，回報下一階段入口；保留可供使用者交接的變更。提交、推送或部署依當次授權進行，不假設「寫文件」包含發布到正式站。
