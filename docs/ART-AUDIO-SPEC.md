# 原創圖片、開放素材與音效規格

更新：2026-09-08。主視覺與 13 使徒須實際生成原創圖片；免費開源／開放授權素材可搭配使用，不能以找素材取代全部生成要求。

## 1. 視覺方向

基調：誇張的反派學院、一本正經的荒謬、巨大災變意象對照小型城市防線。採粗細交錯的原創墨線、印刷網點、非對稱構圖與舞台式側光；城市含台灣街廓、雨棚、丘陵、園區輪廓等一般元素，畫成虛構組合，不使用真實設施的可操作破壞細節。

主色使用墨紫、紙白、銅色；水系青藍、熱系琥珀、土地系青綠作 UI 辨識。每個使徒用不同輪廓、材質、動作與構圖，不以已有角色換顏色。所有繁體中文標題、台詞與數字由 Vue 排版，生成圖片本體不烘焙文字。

創意可以參考超能力學院、喜劇英雄解構、末日巨物與連續分鏡等概念；生成提示詞轉成這些一般描述，不要求複製《我的英雄學院》《一拳超人》或其他作品的角色／造型／分鏡。13 使徒沿用[關卡表](GAME-DESIGN.md)的自創名稱與造型。

## 2. 免費開源／開放授權素材的採用

使用者已同意搜尋及直接下載適合的免費素材。P00／P04 可以下載候選，P06 才把驗收通過的版本列為正式使用；每筆狀態分成「已找到／已下載／已檢視／已整合」，不能混用。

- 優先使用明確 CC0 的粒子、煙霧、衝擊、UI 音效、環境音及城市基礎件；CC BY 素材需保留該版本要求的署名，其他授權按原文核對。
- 「免費下載」「同人」「致敬」與「開放授權」不是同一件事；素材是否可重製／修改／公開部署／再分發，以每項來源和授權證據為準。開源程式的授權不能自動套用到同 repo 的角色圖與音樂。
- 可以用開放授權的原創致敬作品；若仍包含既有作品角色、標誌、原曲、動畫截圖或遊戲拆包素材，不列為正式候選。這延續使用者的原創與版權要求。
- 不從搜尋縮圖、Pinterest 或二手轉載直接認定授權；回到作者／官方作品頁核對。風格不合的 CC0 素材也不可因為免費就硬塞進畫面。
- 初期下載少量代表檔，不整包搬進前端。3D 城市套件若採用，可在製作階段渲染成 2D 背景，不因此把首版改成 3D 引擎。

本次搜尋及下載紀錄見 [素材來源清單](ASSET-SOURCES.md)。後續下載到 `assets/third-party/` 或同等來源目錄；正式轉檔副本才進入 `public/assets/`。保留原檔、原授權、來源頁、下載時間、原包與選用檔 SHA-256，來源壓縮包不必全部納入 repo。

## 3. 最低素材清單與製作階段

| 類型 | 最低內容 | 建議輸出 | 階段 |
|---|---|---|---|
| 首頁主視覺 | 學院與虛構城市 1 幅 | 1920×1080，另裁切手機安全區 | P04 |
| 教授／學員 | 教授 3 種表情，學員 1 個剪影 | 透明 PNG 原稿、WebP 上線 | P04 首版、P06 完整 |
| 13 使徒 | 每關 1 幅獨特造型，共 13 幅 | 1024×1536 原稿，裁切人物卡與過場 | P04 第 1 幅、P06 全部 |
| 13 關場景 | 每關 1 幅完整背景，共 13 幅 | 1600×900，前／中／後景可分層 | P04 第 1 幅、P06 全部 |
| 技能切入 | 三系各至少 2 幅，共 6 幅；終招 1 幅 | 1600×900，留 UI 安全區 | P04 三系各一、P06 補齊 |
| 命中／盾／修復 | 至少 6 種可重用特效圖／紋理 | 透明 PNG／WebP／spritesheet | 可選用開放素材 |
| 防守成功結局 | 至少 2 幅不同鏡頭，依主要防守機制選分支 | 1600×900 | P06 |
| 玩家勝利結局 | 至少 3 幅連續鏡頭，第 13 關再加 3～5 幅終幕 | 1600×900；可重用同世界觀分層 | P06 |
| UI 聲音 | 確認、無法施放、解鎖、切換，共至少 4 cue | Web Audio 或音檔 | P04／P06 |
| 戰鬥聲音 | 三系起手、命中、盾、破防、打斷、修復、終招 | 至少 10 個可區分 cue | P04 首版、P06 完整 |
| 結局聲音 | 城市守住、玩家勝利、全章終幕，各獨立 cue | 原創／開放授權短樂句 | P06 |

生成原稿與上線轉檔分開，不能只交提示詞。圖像可透過動態裁切、分層位移、遮罩、粒子和 UI 字卡做過場，不強制產生影片。每個使徒的終招可以共用技術模板，但必須帶本使徒圖像、色彩／材質與事件差別。

## 4. 可直接交給圖片生成工作的提示詞骨架

**共通：** 原創虛構反派學院遊戲插畫；台灣城市氣氛；誇張戲劇張力與克制喜劇；手繪墨線、網點、紙感與非對稱構圖；墨紫、紙白與銅色；沒有文字、標誌、浮水印；為遊戲 UI 留出安全區；不呈現任何既有作品角色、服裝、專屬符號或著名分鏡。

**首頁：** 丘陵旁的虛構新竹城市，遠方是由不規則紙片和陶片構成的反派學院；前景原創學員拿著過分巨大的畢業計畫卷軸，城市的微型防禦光點一絲不苟地運轉；輕微荒謬而非惡搞已有角色；橫式 16:9，中央左側留標題空間。

**使徒 01：** 空杯使徒；巨大懸空陶器的中空輪廓，不具人類臉部，表面有獨特不對稱窯裂；墨滴違反重力地向上懸浮，細小城市燈點透過空心可見；避免骷髏面具、既有機甲、熟悉的十字或核心配置；直式 2:3。

**技能切入：** 原創水系禁術，碎裂陶環切過乾燥紙面，一條青藍色筆觸捲起虛構城市的光粒；有衝擊方向及速度感，角色與 UI 中央區域保持可讀；橫式 16:9，無文字。

**玩家勝利：** 虛構模擬城市的防禦光網由近至遠解體成紙屑與星屑，原創使徒封印在天空展開，反派學院以盛大的銅色幾何焰火承認學員畢業；沒有真實傷亡特寫；留下壯觀勝利和空曠城市的餘韻，橫式 16:9。

後續 12 使徒依關卡表替換專屬輪廓／材質／動作；不可只更換名稱重用同一張成品。每輪生成保存日期、工具／模型、完整提示詞、參考圖來源、選用版本、修改歷史及檢視結果。

## 5. 演出節奏與聲畫對應

| 事件 | 時長起點 | 畫面 | 聲音 |
|---|---:|---|---|
| 一般施招 | 0.7～1.2 秒 | 技能切入／使徒局部、方向性衝擊、數值差 | 起手＋短命中 |
| 護盾吸收 | 0.5～0.9 秒 | 盾紋擋住衝擊、明示吸收量 | 短悶響，不播放破防聲 |
| 打斷／破防／連攜 | 1.2～2 秒 | 防線裂解或預告劃除、來源行動提示 | 清楚不同的 cue |
| 城市修復／階段轉換 | 0.8～1.5 秒 | 場景局部重組、預告刷新 | 修復／重整音 |
| 使徒終招 | 2.5～4 秒 | 使徒登場 → 禁術圖 → 命中 → 真實戰果 | 蓄力、衝擊、尾響；不能每次等音檔播完才能操作 |
| 城市防守成功 | 3～5 秒 | 防線重亮、城市近景、轉戰報 | 短結束曲 |
| 玩家毀滅成功 | 8～12 秒 | 多鏡頭崩解、學院認可、戰績高光 | 獨立勝利樂句及高潮 |
| 第 13 關終幕 | 額外 8～15 秒，可跳過 | 13 枚封印、城市餘景、畢業宣告 | 全章終幕 cue |

過場可一鍵跳過，已看過可倍速；不要讓玩家每回合等十秒。無聲模式仍看得懂命中、破防與結局；低動態模式用靜態切換與文字差值，保留圖片，不閃爍、不強制震屏。

## 6. 音訊與載入

首次使用者點擊後再解鎖音訊，啟動畫面明示聲音選擇；未解鎖時不報錯、不阻擋開局。音效／音樂分開音量、記住靜音；限制同時播放數量，背景分頁降低或暫停。

短音效可先採 OGG；P06 在 Safari／iOS、Chrome、Edge 實測，必要時提供 MP3／AAC 等 fallback。所有重要狀態同時有可視提示。不要用動畫作品原曲改速、短切或變調當「原創音效」。下載原檔不等於音量、音色與瀏覽器支援已驗收。

圖片採 WebP／AVIF 與尺寸變體，透明素材保留 PNG 原稿；先載本關與下一個必要 cue，後續關卡延遲載入。遵守技術規格 3 MiB 首屏／35 MiB 正式整包預算，原素材來源不算每次遊戲必下載內容。

## 7. 資產 manifest 與驗收

每個正式 cue 必須對應：`asset_id`、類型、關卡／事件、作者／生成工具、來源 URL、授權識別與原文位置、署名、下載／生成日期、原始檔 SHA-256、轉檔關係、輸出檔、尺寸或時長、bytes、alt 文字、檢視狀態。

驗收流程：檔案可讀 → 來源／授權紀錄齊全 → 原創與相似性檢視 → 手機／桌機構圖 → 音訊試聽 → 實際 cue 播放 → 壓縮及載入量測。以上是產品交付檢查，不能用「AI 生成」或「CC0 網站找到」直接代替完成。
