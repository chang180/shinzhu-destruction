# P06 原創音效生成派工單

更新：2026-09-17。這份文件是**可直接派給其他音效／音樂生成 AI 執行**的自包含工作單，不需要對方讀過本 repo 其餘文件。派工者（人類）會把本文件交給執行的 AI；執行完畢後把產出檔案交回本 repo，由負責整合的工程 AI（Claude Code）驗收、格式轉換並接上程式。

**這份文件只涵蓋音效／音樂，不含圖片**（圖片派工見 `docs/P06-ART-GENERATION-BRIEF.md`，已完成）。

## 0. 給執行 AI 的摘要

這是一款虛構反派學院策略遊戲，音效需求是短促、原創、風格克制而不搞笑誇張的效果音與樂句，用來標記戰鬥中的不同事件與結局。**不得**把任何既有動畫、遊戲或影視作品的配樂改速、短切或變調當作「原創音效」交付；也不得使用聽起來會讓人聯想到特定既有作品的音色設計（例如知名遊戲的專屬提示音、知名動畫的角色主題旋律片段）。

## 1. 現況（避免重複產出）

以下音效**已經存在並已整合**，不需要重做：

- `public/assets/p04/impactGeneric_light_000.ogg`（一般命中）
- `public/assets/p04/impactMetal_heavy_000.ogg`（護盾吸收／破陣）
- `public/assets/p04/impactGlass_heavy_000.ogg`（終招／破防）
- `public/assets/p04/impactBell_heavy_000.ogg`（打斷／城市修復）

這四個是 Kenney Impact Sounds（CC0），來源與授權見 `docs/ASSET-SOURCES.md`。目前戰鬥中的施法音是程式即時合成的三個音高（三系各一個純音），不是檔案。

## 2. 待生成清單（共 14 個音檔）

輸出格式：**OGG Vorbis**，單一音效長度 0.3～1.2 秒，樂句類（結局）長度 2～6 秒。取樣率 44.1kHz、單聲道即可，音量正規化到約 -3dB peak（避免削峰），不要內建淡出到完全靜音以外的長尾。檔名＝下表 `key` + `.ogg`。

### A. UI 提示音（4 個，極短、乾淨、不誇張）

| key | 用途 | 描述 |
|---|---|---|
| `ui-confirm` | 確認操作（例如選定手牌、確認換牌） | 短促、清脆的兩音上行點擊聲，類似輕觸陶片或紙張翻動的乾淨聲響，不用電子遊戲罐頭「叮」音效。 |
| `ui-unable` | 無法施放／操作被拒 | 短促的低沉悶音，單一音符，帶一點粗糙的紙張摩擦質感，明確傳達「不行」但不刺耳。 |
| `ui-unlock` | 解鎖新關卡／新內容 | 稍長（約 1 秒）的上行小樂句，三個音符由低到高，帶一點銅器共鳴感，慶祝但不誇張。 |
| `ui-toggle` | 切換設定（例如靜音開關、模式切換） | 極短的中性「喀」聲，機械式開關質感，兩種狀態切換都可共用同一個聲音。 |

### B. 三系施法起手音（3 個，取代目前的合成純音）

| key | 用途 | 描述 |
|---|---|---|
| `cast-water` | 水系技能施放起手音 | 液態流動感，類似水滴滑過陶器內壁再匯聚成一道細流的聲音，短促但有明確的下滑音高走向，時長約 0.5 秒。 |
| `cast-heat` | 熱系技能施放起手音 | 乾燥的爆裂感，類似陶片受熱產生的細微裂響加上一絲空氣震動，短促上揚，時長約 0.5 秒。 |
| `cast-land` | 土地系技能施放起手音 | 厚重的碎裂感，類似土塊或陶土斷裂的低頻震動，時長約 0.5 秒。 |

三者要能在不看畫面的情況下用耳朵分辨是哪一系（配合 `docs/ART-AUDIO-SPEC.md` 的水系青藍／熱系琥珀／土地系青綠视覺對應）。

### C. 城市修復音（1 個，取代目前與「打斷」共用的鐘聲）

| key | 用途 | 描述 |
|---|---|---|
| `repair-chime` | 城市完成修復／回復核心韌性 | 溫暖的多音符上行琶音，類似風鈴或小型金屬片依序敲響，比 `ui-unlock` 更綿長、更有「癒合」的安定感，時長約 1～1.5 秒。 |

### D. 使徒終招（3 個音層，各自獨立）

| key | 用途 | 描述 |
|---|---|---|
| `ultimate-charge` | 終招蓄力階段 | 逐漸增強的低頻嗡鳴加上細微顆粒感的粒子聲，暗示能量正在匯聚，時長約 1～1.5 秒，結尾可以稍微淡出以銜接下一段。 |
| `ultimate-impact` | 終招命中瞬間 | 厚重、有衝擊力的複合聲響（低頻衝擊＋高頻碎裂），比一般命中音明顯更具份量，時長約 0.6～1 秒。 |
| `ultimate-tail` | 終招餘韻尾聲 | 命中之後的殘響延續，類似碎片持續墜落或能量消散的聲音，緩慢淡出，時長約 1.5～2.5 秒。 |

### E. 結局音樂／音效（3 個獨立樂句）

| key | 用途 | 描述 |
|---|---|---|
| `ending-defense-success` | 城市守住（玩家該關失敗） | 平靜、略帶惋惜但不悲傷的短樂句，暗示「城市這次撐過去了」，時長約 3～4 秒，可以有淡出。 |
| `ending-victory` | 單一關卡玩家毀滅成功 | 莊重但帶點荒誕慶祝感的短樂句，銅管或類似音色的上行進行，呼應「畢業」意象，時長約 4～5 秒。 |
| `ending-campaign-finale` | 全戰役終幕（主線或進階通關後的最終慶典） | 比 `ending-victory` 更盛大、更完整的樂句，可以是前者的擴展或變奏，帶有明確的收尾感（漸強後乾淨結束，不是漸弱消失），時長約 5～8 秒。 |

## 3. 交回格式

請把所有輸出檔放在同一層資料夾，並附上一份 `p06-audio-generation.json`：

```json
{
  "date": "西元年-月-日",
  "tool": "你實際使用的工具／模型名稱",
  "assets": [
    {
      "key": "cast-water",
      "description": "你實際做出來的聲音簡述（如果和上面描述有出入，寫實際版本）",
      "file": "cast-water.ogg",
      "duration_seconds": 0.5
    }
  ]
}
```

不需要計算 SHA-256、不需要放進特定 repo 路徑、不需要額外轉檔（MP3/AAC fallback 由整合階段處理）——整合階段會做正規化、瀏覽器相容性測試與程式接線。

## 4. 驗收前提醒

- 每個音效都要是原創合成或原創錄音／原創編曲，不是任何既有作品配樂或音效庫既有素材的改速／變調／混音版本。
- 不要在音檔裡加入語音、旁白或可辨識的文字唸讀。
- 音量要相對一致：不要有某個音效大聲到會蓋過其他音效的感覺（UI 提示音 < 戰鬥音效 < 結局樂句，但差距不要太懸殊）。
