# P01｜Laravel + Vue + SQLite + Boost 基礎

日期：2026-09-08｜狀態：完成

## 交付內容

- Laravel `13.30.1` 根目錄骨架、`public/index.php`、migration、PHPUnit、Pint。
- Vue `3.5.42`、TypeScript `5.9.3`、Vite `8.2.2`、`@vitejs/plugin-vue 6.0.8`、`laravel-vite-plugin 3.2.0`；`resources/js/app.ts` 以 `resources/js/App.vue` SFC 掛載新版頁面殼，避免 runtime-only Vue 無法編譯 template 字串。
- SQLite `database/database.sqlite`（本機生成，檔案不提交）、`.env.example` 的 `DB_CONNECTION=sqlite`、`CACHE_STORE=file`、`SESSION_DRIVER=file`、`QUEUE_CONNECTION=sync`。
- `api-probe/package.json`／lockfile 隔離舊 Node 探測器；根 `package.json` 改為 Vue/Vite scripts，仍保留 `probe:test`、`probe:build`。
- `scripts/configure-boost.php`、`boost.json`、`config/boost.php` 與 [Boost 安裝紀錄](../BOOST-SETUP.md)。
- `tests/Feature/ApplicationFoundationTest.php` 驗證 Vue mount point、SQLite、file cache store、sync queue。
