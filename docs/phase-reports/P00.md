## 遷移邊界

- 根目錄現在是 Laravel 應用，正式入口為 `public/index.php`；Vue/Vite 原始碼在 `resources/`，輸出固定到被忽略的 `public/build/`。
- `server.js`、`api-probe/` 與相關報告保留為 Hostinger 資料來源連線實驗，不再佔用根 npm 的正式啟動角色。
- `docs/index.html`、`docs/app.js`、`docs/game.js`、`docs/style.css` 維持獨立 GitHub Pages 審查入口，沒有被 Laravel 或 Vite import。
- 使用者指定的三個部會資料來源仍依 `README.md`、`api-probe/DATA-SOURCES-FEASIBILITY.md` 與技術規格選用；P02 才建立正式 Laravel adapter。
