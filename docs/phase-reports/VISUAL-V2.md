# 第 2 關至終幕視聽強化：本機交付

日期：2026-10-12。狀態：待驗收。這是本機視聽交付，沒有部署正式站。

## 接手基準

已核對 Claude 的 `abfbb3d` 卡牌規則提交，現行本機 `rules_version` 為 **8.0.0**：手牌上限 4 張、未出牌自動保留、回合補滿、每回合一次換牌，移除手動留牌。此次文案沿用 API 回傳的數值、可用行動與三幕資料；沒有修改 PHP、戰鬥公式、事件契約或另升規則版本。Claude 的規則矩陣與 `data/p10-8/` 屬另一項任務，此報告不替代其規則驗收。

## 交付內容

- **20 張新原稿**：第 2～5 關各有授課、城市、終招、勝利 4 張；主線結業 1 張；進階終幕連續分鏡 3 張。PNG 保存在 `assets/generated/visual-v2/`，每張輸出 1600／1280／768px WebP，共 60 檔。
- **26 個原創聲音單元**：UI 4、三系起手 3、戰鬥 6、終招 3 層、特殊機制 2、四關氛圍 4、收尾 4。保留 WAV 母帶，輸出 OGG 與 MP3 共 52 檔。全部是原創合成與短樂句，未使用第三方錄音或配音；舊 CC0 素材保留供歷史版本查證。
- 集中關卡文案／選圖映射位於 `resources/js/game.ts`，開場採任務、教授台詞與權威教學。第 1 關主美術保留，五位使徒與兩張失敗圖保留。
- 第 2 關以百葉窗、騎樓與錯位日光區別場景；第 3 關採帳冊與園區計量網；第 4 關採丘陵、錯位鏡面與上一手反制；第 5 關採觀測室與分區燈網。三幕以已存幕次、護盾及重整狀態調整前端畫面，沒有新增判定。
- 戰報先顯示實際核心歸零／回合用盡原因，再給教授評語。第 5 關分辨中止重整、啟動後搶先擊敗、重整完成後獲勝及缺少事件證據的中性分支。鏡蔭失敗不憑通用護盾事件臆測「它猜中了」。
- 聲音分為音效與氛圍／樂句兩軌，預設靜音、各軌音量及偏好記憶沿用；每次出牌只播放一次起手，音效最多同時 8 聲，允許自然尾音。終招與結局壓低氛圍；跳過停止演出音效與延遲尾響，離開戰鬥／背景分頁停止氛圍。載入錯誤回退 MP3，失敗不阻擋操作。

## 素材與重製

完整提示詞、身份參考、原稿與轉檔 SHA-256、尺寸及檔案大小見 [`assets/visual-v2-generation.json`](../../assets/visual-v2-generation.json)。參考圖固定晏沉面貌、紫袍與銅色配件，沒有套用外部角色。所有原稿不含 UI 文字，城市為虛構台灣元素組合。

聲音來源、描述、時長、峰值、RMS 與雜湊見 [`assets/visual-v2-audio.json`](../../assets/visual-v2-audio.json)。音效是固定種子的噪聲塑形、陶腔／玻璃／銅聲泛音及原創短旋律；氛圍每段 24 秒，具有淡入淡出以降低循環接縫。

作者工具不加入應用依賴，也不部署：

```text
python scripts/package-visual-v2.py
python scripts/build-visual-v2-audio.py --encoder-dir <local-authoring-tools>
```

使用 Pillow、NumPy，以及 soundfile 0.13.1／lameenc 1.8.1 編碼。腳本重新產出 manifest 會重設審閱標記，重製後需重新檢查。

## 驗證與證據

- `npm run probe:test`：**74 項前端與原型測試通過**，其中 35 項視聽／戰報測試。覆蓋選圖、srcset、真實引擎戰報、四種第 5 關評語、起手去重、分軌、靜音、零音量、背景頁、尾音、跳過、聲部上限、MP3 回退，以及 OGG 同時觸發 error／Promise reject 的競態。
- `npm run typecheck`、`npm run build`、`npm run probe:build` 通過。沒有修改 PHP，未將既有後端測試結果宣稱為本次重跑。專案未配置 ESLint／Prettier，本次未新增依賴，也沒有宣稱通過這兩項。
- `tests/visual-v2.browser.cjs` 對本機 Laravel shell 執行 Chromium：1280／390／320px，各關授課、戰鬥、勝利、失敗及獎勵，共 **51 張畫面**。所有主圖成功解碼、無頁面水平溢出、無腳本或 HTTP 錯誤；重播後 Esc 跳過通過。四關氛圍實際觸發載入，52 個音檔逐一以瀏覽器 AudioContext 解碼。
- 瀏覽器資料使用現行 PHP 引擎生成的開局與勝敗紀錄；僅攔截 API／解鎖與結業狀態以檢查 UI，沒有更動真實存檔。planner 找到勝局只為檢查勝利畫面，不是平衡證據。
- Pages 原型另啟獨立靜態伺服器，頁面載入無腳本錯誤；四個入口檔案在檢查前後位元組一致，Git 正規化內容與 `abfbb3d` 一致，沒有將 Vite 產物寫入 docs。
- 實際載入清單、音檔解碼時長、首屏位元組數與結果見 [browser-results.json](data/visual-v2/browser-results.json)；畫面證據同目錄，20 張圖的總覽見 [contact-sheet.jpg](data/visual-v2/contact-sheet.jpg)。已目視總覽、手機授課、320px 戰鬥與獎勵、桌機及手機進階終幕。

正式交付資料夾共 **14,542,560 bytes（約 13.87 MiB）**；加既有 P04／P06 視聽資產共 **26,568,255 bytes（約 25.34 MiB）**，低於 35 MiB。母帶與原稿不送入首屏；首屏實測 encoded body 為 **1,063,364 bytes（約 1.01 MiB）**，小於 3 MiB，跨來源資源可能因瀏覽器限制回報 0，因此此數字不等同外部字型完整網路流量。
