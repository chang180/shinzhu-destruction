3. 測試結果

HTTP 200 可能只是登入或封鎖 HTML。只有「收到 JSON」代表取得可解析的資料；仍須另確認欄位、資料新鮮度與業務錯誤。主機端不受瀏覽器 CORS 規則限制。

如何判讀

  • 首頁與 JSON 都失敗：先檢查 DNS、TLS、路由與主機出站連線。
  • 首頁成功、JSON 回 HTML：可能需正常工作階段，或被導向登入／錯誤頁。比較直接呼叫與工作階段版本。
  • 403／429：可能是權限、WAF 或限流；不是海外封鎖的充分證據。
  • 本機成功、Hostinger 同網址失敗：保存兩份 JSON 與主機地區，再查 IP／WAF／路由限制。
  • 某個 JSON 成功：只證明該端點此刻可用；實際遊戲要用的每個來源仍須逐一測試。
