# 資料來源可行性盤點（2026-09-07）

背景：實測發現新竹縣政府自有機房（`dip.hsinchu.gov.tw`、`ws.hsinchu.gov.tw`、`www.hsinchu.gov.tw`，見 [HOSTINGER-RESULT.md](HOSTINGER-RESULT.md)）從這台 Hostinger 主機連不上，且直接瀏覽新竹縣自己的資訊平台也找不到遊戲需要的資料。改查 `data.gov.tw` 上，遊戲頁面（`docs/index.html`）底部原本就列的三個資料集，發現它們實際掛在**中央部會**的開放資料平台，不是新竹縣自己的機房，從這台主機**全部可連、可用**。

## 對照遊戲三系技能

| 技能系統 | 對應資料集 | 提供機關 | 主機 | 連線結果 | 內容 |
|---|---|---|---|---|---|
| 水系（SDG 6） | [水庫水情資料](https://data.gov.tw/dataset/45501) | 經濟部水利署 | `opendata.wra.gov.tw` | 可連（TCP 100ms，HTTP 200） | 即時水情 JSON/CSV/XML，含 66 座水庫，確認含新竹地區的**寶山第二水庫（代碼 10405）**、**永和山水庫（代碼 10501）**，欄位含水位、蓄水量、進出流量、降雨量 |
| 水系（SDG 6，補充） | [新竹科學園區用水量統計](https://data.gov.tw/dataset/41280) | 國科會新竹科學園區管理局 | `mas.nstc.gov.tw` | 可連（需帶瀏覽器 User-Agent，預設 curl UA 會被 WAF 擋 403） | CSV，含新竹園區、竹南園區、新竹生醫園區等逐月用水量（噸/日） |
| 熱系（SDG 11・13）／土地系（SDG 15） | [國土利用現況調查鄉鎮市區統計](https://data.gov.tw/dataset/178038) | 內政部國土測繪中心 | `opdadm.moi.gov.tw` | 可連（TCP 80ms，HTTP 200） | CSV，全臺 368 鄉鎮市區，含**新竹縣 13 個鄉鎮市**，93 類土地利用分類，其中「公園綠地廣場」「森林」「農業」等欄位可直接對應綠地／熱島與土地保留兩個技能主題 |

## 判讀

1. **三個既有連結都是可行的**，不需要換掉；`docs/index.html` 頁尾列的三個 `data.gov.tw` 資料集頁面本身只是索引頁，真正的資料下載／API 網址在各部會自己的開放資料平台上，跟新竹縣政府機房完全無關。
2. `mas.nstc.gov.tw` 對預設 curl User-Agent 回 403，換成一般瀏覽器 UA 就變 200——這是常見的簡易 WAF／爬蟲防護，跟先前新竹縣機房那種 TCP 層級直接無回應的地區限制是不同性質的問題，正式串接時記得帶 UA header。
3. 水庫水情資料的水庫是用**數字代碼**識別（如 `10405`），沒有直接附中文名稱，需要自建代碼對照表（寶山第二水庫＝10405、永和山水庫＝10501 已在這次確認）。
4. 目前沒有找到新竹縣specific的「都市熱島」或「綠覆率」專門資料集；「公園綠地廣場」用地面積是目前查到最接近的代理指標，足夠支撐熱系技能的教育文案，但不是精確的熱島量測值，界說明文案時要沿用現有 README 的保守措辭（「具體降溫效果仍需場域量測與模型驗證」）。

## 建議下一步

- 串接時直接打 `opendata.wra.gov.tw`、`opdadm.moi.gov.tw`、`mas.nstc.gov.tw` 這三個部會主機，不要再嘗試新竹縣政府自己的 `dip.hsinchu.gov.tw` / `ws.hsinchu.gov.tw`。
- 三個都只提供整批 CSV／JSON 下載，沒有可篩選查詢參數的正式 REST API；若要即時性資料，建議比照 `weather-map` 專案的做法——後端定期抓取整批資料、篩選新竹縣相關列、寫入快取（如 Redis），前端只讀快取，避免每次玩家動作都重新下載整份檔案。
